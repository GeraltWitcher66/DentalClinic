# دنتا — قالب کلینیک دندانپزشکی

سایت تک‌صفحه‌ای (به‌همراه صفحات جزئیات خدمات) برای کلینیک دندانپزشکی دنتا، ساخته‌شده با
Next.js ۱۴ به‌صورت **خروجی استاتیک** برای میزبانی روی GitHub Pages.

- صفحهٔ اصلی: هیرو، نوار اعتماد، خدمات، چرا دنتا، پزشکان، تجربهٔ بیماران، تور کلینیک،
  پرسش‌های متداول، مراجعه/بیمه و فوتر
- چهار صفحهٔ خدمات: `/services/laminate`، `/implant`، `/orthodontics`، `/cleaning`
- شیت رزرو نوبت (بدون بک‌اند)، صفحهٔ ۴۰۴ اختصاصی

## اجرا

```bash
npm install
npm run dev     # سرور توسعه
npm run build   # ساخت خروجی استاتیک در out/
npm run test:smoke   # آزمون دود روی out/ (بعد از build)
```

## محل تغییر محتوا

تمام متن‌ها، شماره‌ها، خدمات، پزشکان، نظرات، پرسش‌ها و بیمه‌ها در یک فایل‌اند:

```
content/site.js
```

- `site` — نام، تلفن، موبایل/واتس‌اپ، ایمیل، آدرس، ساعت کاری، لینک نقشه، شمارهٔ پروانه
- `services` — هر خدمت با `slug` (آدرس صفحه)، تصویر، معرفی، مدت، مراحل و مراقبت
- `doctors` / `advantages` / `testimonials` / `faqs` / `insurers` / `gallery`

پس از تغییر متن نیازی به دست‌زدن به کامپوننت‌ها نیست.

> **پیش از انتشار واقعی:** شماره‌ها، آدرس، شمارهٔ نظام پزشکی، نام بیمه‌ها و نظرات
> بیماران نمونه‌اند؛ آن‌ها را با اطلاعات واقعی و نظرات دارای اجازهٔ کتبی جایگزین کنید.

## تصاویر

همهٔ تصاویر در `public/images/` با نام ثابت قرار دارند:

| فایل | کاربرد |
| --- | --- |
| `hero.jpg` | پس‌زمینهٔ هیرو (۱۴۰۸×۱۱۵۲) |
| `clinic.jpg` | قاب بخش «چرا دنتا» |
| `service-*.jpg` | عکس دایره‌ای کارت خدمات |
| `doctor-1..3.jpg` | کارت پزشکان |
| `before-1.jpg` / `after-1.jpg` | جفت تصویر اول مقایسهٔ «قبل و بعد» |
| `before-2.jpg` / `after-2.jpg` | جفت تصویر دوم مقایسهٔ «قبل و بعد» |

> تصاویر `before-*.jpg` و `after-*.jpg` نمونه‌اند و نتیجهٔ درمان واقعی نیستند؛ پیش
> از انتشار با عکس‌های واقعی یک بیمار (همان زاویه و نور، با رضایت کتبی) جایگزین شوند.

برای جایگزینی، فقط فایل را با همان نام و نسبت تصویر تقریباً یکسان عوض کنید. منبع فعلی
تصاویر در `public/images/README.txt` ثبت شده است. عکس هیرو عمداً برش خورده تا تابلوی
انگلیسی اتاق درمان در کادر دیده نشود؛ اگر عکس را عوض کردید، برش و `width`/`height` در
`components/Hero.jsx` را به‌روز کنید.

## فونت

وزیرمتن **محلی** سرو می‌شود (بدون CDN گوگل):

```
public/fonts/vazirmatn-arabic.woff2
public/fonts/vazirmatn-latin.woff2
public/fonts/vazirmatn-latin-ext.woff2
```

`@font-face`ها در ابتدای `app/globals.css` هستند و مسیرشان با `basePath` هم‌خوان است.
اگر نام ریپازیتوری را عوض کردید، این سه مسیر و `lib/basePath.js` و `next.config.mjs`
باید هم‌زمان تغییر کنند.

## استایل‌ها

- `app/globals.css` — توکن‌های رنگ، فاصله، تایپوگرافی و بخش‌های صفحهٔ اصلی
- `app/sections.css` — بخش‌های جدید (نظرات، گالری، پرسش‌ها، مراجعه)، صفحات خدمات و ۴۰۴

پالت: کرم `#FAF9F6`، مشکی مات `#1A1A1A`، طلایی مات `#C5A059`. Tailwind استفاده نمی‌شود.

## استقرار روی GitHub Pages

1. مخزن را روی شاخهٔ `main` پوش کنید.
2. در Settings → Pages، گزینهٔ Source را روی **GitHub Actions** بگذارید.
3. `basePath` در `next.config.mjs` باید دقیقاً نام مخزن باشد (`/DentalClinic`).
4. ورک‌فلو `deploy.yml` سایت را روی هر push به `main` منتشر می‌کند.

## بررسی‌های خودکار

- `.github/workflows/deploy.yml` — ساخت و انتشار
- `.github/workflows/quality.yml` — ساخت، آمار `test:smoke` و Lighthouse
- `scripts/smoke.mjs` — وجود بخش‌ها، چهار صفحهٔ خدمات، ۴۰۴، فونت‌ها، تصاویر و
  صحت همهٔ لینک‌های داخلی خروجی را بررسی می‌کند
- `lighthouserc.json` — حدهای عملکرد/دسترس‌پذیری/SEO (در حال حاضر هشدار، نه خطا)

## نکته‌های دسترس‌پذیری

- لینک «پرش به محتوای اصلی» در `app/layout.jsx`
- شیت رزرو: تلهٔ فوکوس، بستن با Escape و بازگشت فوکوس به دکمهٔ بازکننده
- فرم رزرو: `aria-invalid`، پیام خطای `role="alert"` و پیام موفقیت `role="status"`؛
  شمارهٔ موبایل با ارقام فارسی/عربی هم پذیرفته می‌شود
